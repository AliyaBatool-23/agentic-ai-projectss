# agentic-ai-projects
# Agentic AI — Course Project Portfolio

University of Layyah Agentic AI Short Course Program 
This repository contains all seven projects for the Agentic AI
Each project lives in its own folder with its own README, requirements, and setup instructions.

## Projects
Project 1 — Intelligent Task Execution Agent 
Project 2 — Knowledge-Based Decision Agent 
Project 3 — Multi-Agent Problem Solving System
Project 4 — Automated Document Processing System 
Project 5 — Intelligent Communication Assistant 
Project 6 — Telegram Agentic AI Assistant 
Project 7 — AI Procurement Intelligence & Negotiation Agent
## Tech Stack

- **Language:** Python 3.10+
- **LLM Provider:** Groq (`openai/gpt-oss-120b`)
- **Frameworks:** LangChain, LangGraph
- **UI:** Streamlit (Projects 1-5, 7), Telegram Bot API (Project 6)
- **Vector DB:** ChromaDB
- **Structured Output:** Pydantic
- **Integrations:** Brevo (email), Pushover (notifications), Telegram Bot API

## Repository Rules
- Each project is independent, original work by the author.
- See each `project-0X/README.md` for setup and run instructions.
